# Good Measure Studio — Spatial direction

An original, complete website concept for a Sevenoaks/Kent web design business. This direction draws loosely on the spacious, gallery-like feeling of Stereotropism, but uses original composition, copy, graphics and code. The visual tiles describe real services; they are not client case studies.

## Preview locally

Open `index.html` in a browser, or run a local static server such as `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Deploy on GitHub Pages

Publish the repository's `main` branch from its root folder in **Settings → Pages**. The site has no build step or dependencies. The `.nojekyll` file keeps the output as plain static files.

## Before commercial launch

- Replace the contact placeholder with a verified email address, phone number or form service, and test it end-to-end.
- Replace concept pricing with confirmed prices, terms, inclusions, tax information and delivery capacity.
- Connect a domain you own in GitHub Pages settings, then add the required DNS records. Do not add a `CNAME` until the domain is confirmed.
- Add analytics only after choosing a provider and publishing the necessary privacy/cookie information.
- Review business details, legal pages, accessibility and final copy.

No proprietary reference-site assets or code are included.
